Hey, I'm Antonino — I run AMVIdealab, a web development company based in Sicily, Italy, where we build applications mostly in Ruby on Rails.

Outside of that, I like building open source web projects on my own time — HTML, CSS, Tailwind CSS, Ruby, Rails — under AscWebApps, and I contribute in the same spirit to SmartGioiosa, a local association. Lately a good chunk of that time has gone into figuring out how AI fits into a Rails stack: tools like RubyLLM, semantic search, chatbots that feel genuinely integrated, not bolted on.

This blog is where I write it all down. Two ongoing series right now:

- **VicinoTe** — a from-scratch Rails tutorial building a local services marketplace, from the first `rails new` to an AI-powered advanced module.
- **ai-with-ruby** — shorter posts on bringing AI features into Ruby and Rails apps.

Get in touch via the email and links in the footer.
